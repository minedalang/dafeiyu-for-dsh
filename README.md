# 大肥鱼 · AI 自主桌面宠物（DSH 联动版）

基于 [MerZlin/dsh-pet-indesktop](https://github.com/MerZlin/dsh-pet-indesktop) 二次开发，在保留小鲸鱼形象和原有 WebM 动画的基础上，加入 **AI 自主生活、生命状态、角色对话，以及 DeepSeek Harness（DSH）任务状态与动作双向联动**。

> **本分支只支持 DSH 作为任务 Agent。** OpenClaw、Claude Code、Cursor、OpenCode、自定义 Agent 桥接均已从本分支的 Agent 联动能力中移除；普通聊天仍支持可配置的模型服务（包括 Claude API），不受影响。它是独立桌宠程序，不安装 DSH 也能运行基本桌宠与自主生活功能。

## 功能概览

| 功能 | 说明 |
|---|---|
| AI 自主生活 | 模型根据本地时间、生命状态、鼠标互动、最近经历，安排吃饭、午睡、工作、娱乐等行为 |
| 生命系统 | 精力、饥饿、困意、心情；在本地保存状态，支持有限的离线睡眠补算 |
| 连续活动 | 利用已有的 WebM 动画连续表演，不需要每播放一次都重新请求模型 |
| AI 对话 | 独立聊天 API、会话历史、角色性格、主动搭话与点击回应 |
| 自主识屏 | 默认不启用，授权后按设置对白名单前台窗口采样；注意图片可能发送至所选模型提供方 |
| DSH 状态联动 | DSH 思考、工作、审批、失败和完成时，同步显示桌宠工作状态与提醒 |
| DSH 主动控制 | DSH 可调用 `pet_action`，决定桌宠情绪、现有动画、短台词、优先级与短时持续控制 |
| 动画清单工具 | DSH 先调用 `pet_animations` 获得真实素材名称，避免编造动作 |

## AI 分工

```text
                      ┌───────────────────────┐
                      │  DSH Agent 主聊天界面  │
                      │  搜索 / 浏览 / 编程     │
                      │  感知内容并决定反应     │
                      └───────────┬───────────┘
                                  │
                       pet_action / 状态事件
                                  │
                                  ▼
┌──────────────────────────────────────────────────────────┐
│                     大肥鱼桌宠                            │
│                                                          │
│  DSH 任务期间：校验指令 → 现有动画 + 气泡 → 任务结束        │
│  DSH 空闲期间：自主生活模型 → 日常活动、情绪、主动搭话      │
│  用户直接互动：拖动 / 点击 / 普通角色聊天                  │
└──────────────────────────────────────────────────────────┘
```

**谁感知，谁决策：** DSH 阅读 B 站字幕、网页、视频画面（需相关插件实际提供）后，由 DSH 自己决定是否需要让小鲸鱼反应；小鲸鱼只验证并呈现该动作。DSH 没有获得实际视频内容时，不应假装已经看过内容。

**控制权：** DSH 发出的表达请求有短时优先权，降低与大肥鱼自主动作互相打断的概率；用户互动、授权和安全提示仍保留优先级。具体行为取决于正在播放的活动状态和动作素材。

## Windows 快速开始

1. 使用本仓库的 `1-Install-Windows.bat` 准备环境（推荐先备份项目及桌宠配置）；然后运行 `2-Run-Windows.bat` 启动源码。
2. 在「AI 设置」中配置普通聊天与自主行为所用模型。是否启用自主识屏由你单独决定。
3. 如需 DSH 联动，请先单独安装并启动 DSH，然后在大肥鱼右键菜单「Agent 联动」中打开 **DeepSeek Harness (DSH)**，授权安装或更新桥接插件。
4. 完全退出并重启你正在使用的 DSH Web / Desktop Profile，保证新版插件重新加载。
5. 在 DSH 中调用 `pet_animations` 查询动作清单，再调用 `pet_action` 测试动作和气泡。

例如在 DSH 中说：

> 请先调用 pet_animations 查看大肥鱼真实支持的动画，再调用 pet_action，让她开心地说「找到有趣的内容啦！」。

`pet_action` 兼容以下参数：

```json
{
  "mood": "happy",
  "speech": "找到有趣的内容啦！",
  "duration_seconds": 8,
  "priority": "normal"
}
```

需要指定真实动画时，额外传 `animation`，值必须与 `pet_animations` 返回的名称**完全一致**。`mood` 兼容 `search`、`watch`、`think`、`happy`、`work`、`idle`。

> 当前 DSH 插件里注册两个入口：`dsh-pet-bridge`（监听 Agent 状态）和 `dsh-pet-actions`（注册模型工具）。如果 DSH 看不到 `pet_action`，先检查所在 Profile 是否安装了新版桥接，并重启 DSH。

## 刷 B 站时的动作反馈

DSH 能在模型可见的工具事件里识别部分 B 站搜索、浏览、播放操作、整理阶段，并触发简单状态反馈。要让小鲸鱼**真正针对视频内容吐槽**，必须由 DSH 的相关工具或插件实际获取字幕、画面或文字内容，DSH 再自行调用 `pet_action`。

- **自动阶段同步**只说明发生了相应工具活动，不能证明 DSH 真的观看了视频画面。
- B 站插件若把所有行为隐藏在后台、没有向 DSH 提供 Agent 工具事件，普通桥接不能推断出每段视频的内容。
- 不会为实现联动而默认持续录屏，也不在常规事件日志中保存网页全文或 URL。

## 聊天框与 Agent 的关系

大肥鱼保留原来的角色聊天窗和快捷气泡，用于聊天与日常互动；**DSH 是唯一电脑任务 Agent 入口**，电脑任务请在 DSH 的聊天窗口执行。

旧的 `/agent` OpenClaw 指令已经停用，输入时会提示前往 DSH，**不会在普通聊天中悄悄转发到其他 Agent**。本版不提供“大肥鱼聊天窗直接提交 DSH 任务”的会话接口，请不要将状态桥接误认为聊天接口。

## 隐私、权限与费用

- 普通聊天、自主生活和 DSH 分别使用各自配置的模型与权限；自主生活模型不会因 DSH 已安装而自动取得电脑操作权限。
- `pet_action` 只请求桌宠动作和气泡，不能通过该工具执行系统命令、任意访问磁盘或接管鼠标。
- 动作执行回执确认本地接收/尝试执行，不等于确认整个动画播完。
- 普通聊天与自主行为模型调用可能分别计费，DSH 自身还会消耗自己的模型及工具额度。
- 第三方 B 站插件应由用户自行评估登录状态、数据授权与自动评论等行为。建议关闭自动评论等公开动作，除非你确实需要。

## 开发与排错

技术：Python / PySide6 / WebM 动画；DSH 桥接使用 Node 插件和本地事件通道。

- `pet/autonomy.py`：自主生活决策与 DSH 控制权协调
- `pet/agent_link.py`：**仅 DSH** 状态监听、动作分发及插件安装
- `pet/dsh_pet_feedback.py`：DSH 动作验证与动画清单
- `integrations/dsh-pet-bridge/`：DSH 状态及 `pet_action` / `pet_animations` 插件
- `scripts/Test-PetAction.ps1`：本地联动诊断（绕开 DSH 模型）
- [DSH-only 升级说明](DSH-ONLY-UPGRADE.md)：如何从旧版迁移、剩余限制和测试状态

如 DSH 已能正常调用 `pet_action`，更新时请**保持原 DSH 配置**，先备份，再逐文件合并并重新加载桥接插件；不要无条件覆盖本机有个人修改的较新代码。
